# NX Alive

**Characters that live inside products.**

NX Alive is a character creation and runtime platform for expressive 2D mascots, assistants, creatures and product characters.

The project is starting with a deliberately small foundation:

- a portable `.character.json` format;
- a framework-agnostic core;
- a React/SVG runtime;
- a visual Studio;
- the PING mascot as the first real stress test.

> Status: Gate 0 — foundation in progress.
